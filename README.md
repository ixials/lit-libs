# Lit Libs

Lit Libs is a friendslop educationmaxxing mashup of Mad Libs and Cards Against Humanity, originally created to explore the linguistics of Gen Z and Gen Alpha slang. Be aware that this multiplayer game is not PG, each card is explained on the flip side, and all natural language is grammatical and interesting <3
